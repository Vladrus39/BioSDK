# BioGPU-A1 Power-PC / Workstation Spec

## Minimum for Zenodo/replay full sweeps

- CPU: 8 cores
- RAM: 32 GB
- Storage: 1 TB SSD/NVMe
- OS: Ubuntu 22.04/24.04 or equivalent Linux
- GPU: not required for current replay/readout sweeps

## Recommended

- CPU: 16+ cores
- RAM: 64 GB
- Storage: 2 TB NVMe + external/NAS backup
- UPS and power meter
- Separate data disk for raw traces and result bundles

## Lab/live recommendation

- Vendor acquisition PC should be stable and isolated from non-lab software.
- BioGPU analysis workstation can be separate from acquisition PC.
- Use result bundles to move data between acquisition and analysis machines.
