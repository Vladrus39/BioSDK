# Enterprise Test Access Model

## What beta users can do

- run replay benchmarks
- upload or import compatible HDF5/NWB/spike data
- call read-only API/mock adapters
- validate result bundles
- inspect audit logs
- compare decoders and shuffle baselines

## What beta users cannot do by default

- perform live wetware actuation
- issue electrode stimulation commands
- access vendor pinout/wiring routines
- change media/environment conditions
- claim GPU replacement or live BioGPU proof

## Commercial path

1. Developer Evaluation
2. Enterprise Read-Only BioSDK
3. Enterprise Live Shadow BioSDK
4. Lab-Approved Closed Loop Add-on
