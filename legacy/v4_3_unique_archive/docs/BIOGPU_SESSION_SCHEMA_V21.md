# BioGPU v2.1 Session Schema

v2.1 adds a session schema so replay, power-PC and future live-MEA runs can be tracked consistently.

Session modes:

- `replay_local`
- `power_pc_full`
- `live_mea_dry_run`
- `live_mea_vendor`

The live modes are not active biological protocols; they are integration contracts requiring vendor backend and qualified lab SOPs.
