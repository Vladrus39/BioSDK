# BioGPU v4.0 Dataset/API Expansion Plan

The current project has proven the architecture mainly on Zenodo preprocessed MEA data. Before external beta, the project must broaden validation.

## Required dataset/API expansion

1. **Zenodo 14363732 raw HDF5** — validate raw recordings, TTL/stimulus markers and raw-derived windows.
2. **DANDI / NWB discovery pack** — find datasets with units + intervals/trials/stimulus for task-aligned benchmarks.
3. **Allen Brain Observatory / AllenSDK** — add visual coding/orientation-like benchmarks.
4. **FinalSpark read-only/live HDF5** — first remote wetware API path without actuation.
5. **3Brain / Axion / MCS exported-data adapters** — enterprise compatibility before live drivers.

## Rule

No dataset/API result is allowed to become a strong product claim unless it includes split policy, negative controls, shuffle baseline, confidence intervals and result bundle.
