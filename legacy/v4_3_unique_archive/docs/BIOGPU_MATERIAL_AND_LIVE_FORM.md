# BioGPU Material and Live Physical Form

## Selected first material

**2D lab-grown neuronal culture on MEA/HD-MEA.**

The cells are real living neurons. The geometry, chamber, chip and stimulation/readout protocol are engineered.

## Natural or artificial?

- Natural: neurons, synapses, spikes, biological adaptation.
- Artificial/engineered: MEA chip, culture chamber, stimulation encoding, readout software, environment control.

So BioGPU is a **hybrid living-electronic computing substrate**.

## First prototype form

```text
sealed cartridge / MEA dish
+ living 2D neural culture
+ culture medium
+ electrode grid
+ amplifier/stimulator
+ controller PC
+ incubator/environment module
```

## Material ladder

1. Prototype A — 2D neuronal culture on MEA/HD-MEA: first target.
2. Prototype B — 3D organoid/neurosphere on MEA: later.
3. Prototype C — engineered patterned co-culture: future optimized BioGPU substrate.
