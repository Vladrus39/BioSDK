# BioGPU Wet-Lab Boundary

The project goal remains the design and implementation of a real BioGPU.

However, this repository is currently a **software/research engineering core** and therefore uses the following boundary:

## Allowed here

- architecture;
- code contracts;
- replay and benchmarking;
- dataset analysis;
- hardware/software planning;
- checklists for future live deployment.

## Deferred to qualified lab / vendor documentation

- exact cell-culture recipes and formulas;
- operational cultivation instructions;
- exact biological handling procedures;
- precise stimulation limits for live tissue;
- vendor-specific physical connection procedures.

## Why this boundary exists

A real BioGPU must be built responsibly: the software should be ready, but the live biological implementation should be carried out only with appropriate expertise, SOPs and equipment.
