# Public Data Evidence Notes v0.8

## Key update

The project now develops on public real data paths, not only simulated MEA.

## Evidence items

### Zenodo 14363732

MEA2100-mini public dataset with HDF5 raw files and preprocessed spike times. Immediate use: ingestion and spike profiling.

### DANDI Archive

NWB-based public archive. Immediate use: local NWB unit/spike ingestion. Next use: stimulus-window mapping for task-aligned benchmarks.

### DANDI 000469

Human single-neuron Sternberg working-memory dataset. Strong candidate for real task-aligned spike analysis because public materials describe spike times, stimuli and behavior in NWB.

### BRC arXiv 2602.05737

Closest external target for BioGPU-like biological reservoir computing. Need code/data access for reproduction.

## Project decision

v0.8 adds real-data ingestion and task-aligned benchmark scaffolding. v0.9 should run on downloaded public files and produce a first real-data report.
