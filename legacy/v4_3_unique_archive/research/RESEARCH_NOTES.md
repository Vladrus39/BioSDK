# Research Notes

## Current project thesis

A realistic BioGPU cannot begin by attaching to a random brain fragment. It should begin as a layered architecture:

```text
V1-inspired architecture + SimulatedMEA + clear data model + benchmark suite
→ real MEA living reservoir
→ HD-MEA closed-loop system
→ organoid/3D-MEA future
```

## Key unresolved questions

1. Can a living reservoir improve noise robustness or adaptation compared with digital baselines?
2. Can energy-per-useful-task beat GPU/CPU once host and life support are included?
3. Can we impose V1-like organization externally through encoding/feedback?
4. Which real MEA platform gives the best API access for closed-loop experiments?
