# BioGPU-Core v3.0 — Whitepaper / Paper Package

v3.0 consolidates the project into a single scientific and engineering package.

It includes:

- main whitepaper;
- methods draft;
- results template;
- limitations;
- roadmap to live BioGPU;
- claim ladder;
- reproduction checklist;
- figure plan;
- machine-readable manifest.

## Scientific boundary

v3.0 does **not** claim that a live BioGPU has already outperformed GPU/CPU hardware. It defines what is supported now, what is partial, and what requires power-PC or live-lab evidence.

## Safety boundary

v3.0 does not provide wet-lab culturing recipes, live stimulation parameters, pinouts, wiring procedures or vendor-specific replacement documentation.
