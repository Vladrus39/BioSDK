# BioGPU-Core v3.9 — Enterprise Packaging / Licensing Layer

v3.9 converts BioGPU-Core into a commercial BioSDK package. It does not claim that
BioGPU has replaced a GPU and it does not enable live biological actuation by default.

## Commercial product

BioGPU-Core Enterprise BioSDK provides:

- replay/local validation;
- read-only external API/export integration;
- BioGPUTrace export;
- benchmark/readout/report generation;
- BioLLM tool interface;
- safety boundary and audit/result bundles;
- partner onboarding and enterprise support boundaries.

## License ladder

1. Developer Evaluation BioSDK.
2. Enterprise Read-Only BioSDK.
3. Enterprise Live Shadow BioSDK.
4. Lab-Approved Closed Loop Add-on.

The first real paid product should be Enterprise Read-Only BioSDK. Live Shadow and
Closed Loop are higher-value tiers, but only after a partner/lab environment exists.

## Why staged access matters

Full access immediately would reduce trust and increase safety/compliance risk. A
staged SDK is more credible for enterprise customers: validate read-only access,
audit logs and result bundles first; only then negotiate live-shadow or approved
closed-loop scope.
