## Current ideal material choice

The first real BioGPU prototype should use a **2D mixed cortical-like neuronal network on MEA/HD-MEA**.

Preferred starting direction:

- human iPSC-derived neurons;
- optional astrocyte/glial support;
- PDL/PEI + laminin/fibronectin class surface stack;
- BrainPhys or Neurobasal Plus/B-27 Plus class neuronal medium system;
- HD-MEA preferred, 60-channel MEA acceptable for low-cost bridge prototype.
