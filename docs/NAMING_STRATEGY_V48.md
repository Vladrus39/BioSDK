# Naming Strategy v4.8

## Keep BioGPU-Core?

Yes. Keep **BioGPU-Core** as the technical core name. It is already used throughout the repository, archives, evidence, scripts and documentation.

## Risk

The term GPU can create an expectation of CUDA/RTX/LLM replacement. External material must avoid this claim unless future live experiments prove a specific narrow advantage.

## Recommended external stack

- **BioGPU-Core** — core engine / repository / technical kernel.
- **BioCompute Runtime** — main external product.
- **BioSDK / Living Compute SDK** — developer package.
- **NSI-1.0 / Neural Substrate Interface** — interface standard.
- **BioCompute Control Plane** — hosted/on-prem server layer.
- **BioCompute OS** — long-term OS-like target.

## Commercial positioning

Sell stages, not fantasies:

1. BioSDK / Runtime for replay and read-only workflows.
2. Hosted/on-prem control plane for enterprise/lab users.
3. Live Shadow module for approved partners.
4. Lab-Control add-on for protocol-approved closed-loop workflows.
5. BioCompute OS after device/session management, scheduler, permissions and safety supervisor are real.
