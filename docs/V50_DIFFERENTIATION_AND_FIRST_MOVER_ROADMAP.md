# v5.0 Differentiation and First-Mover Roadmap

This release adds the project’s unique-value targets directly into the roadmap.

## Why this matters

The project must not become just another MEA parser or wetware API wrapper. Its strongest path is a vendor-neutral OS/runtime layer that connects data, devices, APIs, experiments, LLMs, safety and evidence.

## Key strategic shift

From:

```text
BioGPU as possible GPU replacement
```

To:

```text
BioGPU-Core as the kernel of BioCompute Runtime and future BiC OS:
A vendor-neutral interface, runtime, benchmark, evidence and AI-agent layer for living neural compute.
```
