# v4.9 Naming + OS Strategy Summary

v4.9 corrects the product identity after external naming checks and adds a differentiated OS roadmap.

## Decisions

```text
Keep: BioGPU-Core
Use: BioSDK / Living Compute SDK
Use: BioCompute Runtime
Use: NSI-1.0 / Neural Substrate Interface
Use as working codename only: BiC OS
Do not use as primary public brand: SomaOS
```

## BiC OS meaning

BiC OS may stand for:

```text
BioCompute OS
Biological Interface Compute OS
Biological Compute Control OS
```

It is not legally cleared.

## Main differentiator

The project should not claim to be the first biological OS. It should aim to be the best vendor-neutral interface/runtime layer connecting living neural compute, LLM agents, data/API adapters, safety policies and result bundles.
