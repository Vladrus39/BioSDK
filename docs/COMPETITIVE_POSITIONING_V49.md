# Competitive Positioning v4.9

## We are not first in the broad field

Existing systems already cover important parts of the space:

```text
Cortical Labs / CL1 / biOS    vertical wetware computer + API
FinalSpark NeuroPlatform      remote wetware/organoid API platform
RTXI                          real-time closed-loop experimental interface
Open Ephys                    open electrophysiology acquisition/control ecosystem
NWB                           neurophysiology data standard
DANDI                         neurodata archive ecosystem
MEA vendors                   acquisition/stimulation hardware and vendor software
```

Therefore BioGPU-Core must not claim to be the first biological computer or first biological operating system.

## Our angle

BioGPU-Core should compete as a **vendor-neutral runtime/interface layer**, not as a single wetware device.

```text
Replay datasets
+ NWB / DANDI / Allen
+ MEA / HD-MEA exports
+ FinalSpark / vendor / CL-like API adapters
+ LLM tool interface
+ benchmark suite
+ safety supervisor
+ result bundle evidence
+ enterprise/on-prem/hosted paths
```

## Strongest claim

```text
BioGPU-Core is a vendor-neutral BioCompute Runtime / BioSDK and NSI interface draft for living neural compute workflows.
```

## First-mover opportunities

1. Cross-vendor biological compute interface.
2. LLM-native biological compute tool layer.
3. Reproducible result-bundle evidence standard for wetware/replay compute.
4. Maximum-safe-access beta model.
5. Path from SDK to runtime to OS-like control plane.

## Evidence required before stronger claims

```text
power-PC full_shuffle_1000
extended_methods_5000
bootstrap confidence intervals
raw HDF5 / TTL reconstruction
DANDI / NWB parser
AllenSDK benchmark
at least one external read-only API validation
private beta result bundles
```
