# BioSDK vs FinalSpark Neuroplatform — Сравнительный анализ

**Дата**: 2026-05-12 | **Версия**: v9.5

---

## 1. Что они из себя представляют

| Характеристика | BioSDK | FinalSpark Neuroplatform |
|---------------|--------|-------------------------|
| **Тип** | Стандарт/SDK (инфраструктура) | Платформа (железо + софт) |
| **Что даёт** | Единый API для любых нейроданных | Доступ к живым органоидам |
| **Аналог** | Vulkan (для GPU), ROS (роботы), FHIR (медицина) | AWS + лаборатория в одном |
| **Установка** | `pip install biosdk` | Закрытый Jupyter-окружение |
| **Цена** | Бесплатно (open-source) | Бесплатно для университетов |
| **Железо** | НЕ требуется | 4 MEA, 16 органоидов |
| **Данные** | Любые форматы (HDF5, NWB, EDF, CSV, XLSX) | Только свои MEA (30 кГц, 8 каналов) |

## 3. Ключевое отличие: СТАНДАРТ vs ПЛАТФОРМА

**BioSDK — это стандарт, а не платформа.** Он не заменяет FinalSpark —
он дополняет его, давая общий язык для сравнения данных из разных источников.

| Сценарий | FinalSpark | BioSDK |
|----------|-----------|--------|
| Подключиться к живым органоидам | ✅ Да | ❌ Нет (нужен адаптер + токен) |
| Сравнить MEA FinalSpark с MEA Giroldini | ❌ Нет | ✅ Да (через NSI-1.0) |
| Сравнить MEA с EEG | ❌ Нет | ✅ Да (6 модальностей) |
| Классифицировать стимулы | ✅ Частично (SpikeSorting) | ✅ Да (MLPipeline) |
| Safety gates с Shannon limits | ❌ Нет (StimParamLoader — только настройка) | ✅ Да (4 проверки) |
| Evidence bundle с подписью | ❌ Нет | ✅ Да (SHA256 + HMAC) |
| pip install за 5 секунд | ❌ Нет (приватный пакет) | ✅ Да |
| Кросс-датасет сравнение | ❌ Нет | ✅ Да (6 датасетов) |
| Работа без интернета | ❌ Нет | ✅ Да |

## 4. Взаимодополняемость

BioSDK и FinalSpark **не конкурируют** — они решают разные задачи:

```
Пользователь хочет:
│
├── Поработать с живыми нейронами
│   → FinalSpark Neuroplatform (железо + API)
│
├── Сравнить свои данные с другими форматами
│   → BioSDK NSI-1.0 (унифицированный интерфейс)
│
├── Запустить closed-loop на органоидах
│   → FinalSpark (железо) + BioSDK (safety gates + evidence)
│
└── Опубликовать воспроизводимые результаты
    → BioSDK (evidence bundles с криптоподписью)
```

**Идеальный сценарий**: FinalSpark даёт доступ к живым нейронам, BioSDK даёт стандартный интерфейс для сравнения их данных с чем угодно ещё (MEA других производителей, EEG, симуляторами).

## 5. Технические различия

### 5.1. Обработка спайков

| | FinalSpark np-utils | BioSDK NSI-1.0 |
|--|--------------------|-----------------|
| Метод | SpikeSorting: ICA/PCA + HDBSCAN/OPTICS | feature_vector: RMS, MAV, ZC, VAR, PEAK, SKEW на окно |
| Вход | Сырые спайки из InfluxDB | Окна сигнала (n_channels × n_samples) |
| Выход | Кластеры спайков + графики | Вектор признаков (n_channels × 6) |
| Совместимость | Только FinalSpark MEA | Любой формат через адаптер |

### 5.2. Стимуляция

| | FinalSpark StimParamLoader | BioSDK Safety Gates |
|--|---------------------------|---------------------|
| Функция | Настройка + отправка параметров | Валидация безопасности |
| Проверки | Автоматическая проверка на ошибки | Shannon limits: 100 uA, 200 nC, 500 Hz, 3600s |
| Прервать стимуляцию | Да (disable all) | Да (kill switch) |
| Интерактивный предпросмотр | Да (Plotly) | Нет |
| Кросс-платформенность | Только FinalSpark | Любая платформа |

**Вывод**: StimParamLoader удобен для НАСТРОЙКИ стимуляции на FinalSpark. BioSDK safety gates нужны для ВАЛИДАЦИИ безопасности на любой платформе. Они дополняют друг друга.

### 5.3. Масштаб

| | FinalSpark | BioSDK |
|--|-----------|--------|
| Данных | 18+ TB (свои органоиды) | 6 датасетов, 5 форматов, 4 модальности |
| Каналов | 32 (4 MEA × 8) | 1-96 (зависит от адаптера) |
| Частота | 30 кГц | 100 Гц – 30 кГц |
| Пользователей | 9 институтов (март 2025) | 0 бета-пользователей (пакет готов) |

## 6. Что BioSDK может дать FinalSpark

1. **NSI-1.0 адаптер** — унифицированный доступ к их данным через стандартный API
2. **Кросс-модальное сравнение** — FinalSpark MEA vs Giroldini MEA vs DANDI spike vs EEG
3. **Safety gates** — валидация параметров стимуляции по Shannon limits
4. **Evidence bundles** — криптографически подписанные результаты для публикаций
5. **Dashboard** — мониторинг состояния экспериментов

## 7. Что FinalSpark может дать BioSDK

1. **Живое железо** — первый реальный closed-loop на биологических нейронах
2. **Валидация стандарта** — доказательство, что NSI-1.0 работает с живыми органоидами
3. **Сообщество** — 9 институтов уже используют платформу
4. **Публикация** — Frontiers in AI 2024 с цитированием BioSDK как стандарта

---

## 8. Честный вывод

**BioSDK и FinalSpark не конкуренты, а потенциальные партнёры.**

- FinalSpark строит платформу для доступа к живым нейронам
- BioSDK строит стандарт для работы с ЛЮБЫМИ нейроданными
- Вместе: стандартизированный доступ к живым нейронам с воспроизводимыми результатами

**Единственный конфликт**: оба проекта используют слово "Neuroplatform".
FinalSpark — это железная платформа. BioSDK NSI-1.0 — это софтверный стандарт.
Разные уровни стека.
