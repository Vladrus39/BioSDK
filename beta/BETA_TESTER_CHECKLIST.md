# BioGPU Private Beta Tester Checklist

## Before starting

- [ ] Confirm you are testing software/replay/read-only modes only.
- [ ] Do not connect live stimulation or vendor write controls unless separately approved.
- [ ] Install from the v4.7 package.
- [ ] Run smoke check.
- [ ] Validate sample and/or full dataset.

## Required beta test runs

- [ ] Local smoke test.
- [ ] Dataset import validation.
- [ ] Compact v3.3 sweep.
- [ ] Compact lineage-strict v3.6 sweep.
- [ ] BioLLM tool demo if relevant.
- [ ] Result bundle export.

## Feedback required

- Installation problems.
- Runtime errors.
- Dataset schema mismatches.
- Result reproducibility notes.
- Requested enterprise features.
