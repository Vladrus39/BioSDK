# Private Beta Acceptance Criteria — v4.7

A private beta is acceptable when:

- current tests pass on the beta host;
- full preprocessed data asset validates;
- compact sweeps reproduce evidence-family results;
- result bundles are generated and downloadable;
- unsafe live-control fields are rejected;
- tester can run at least one custom/uploaded-data import path;
- feedback form is completed.

A beta is not acceptable if it requires chat-history knowledge to run. v4.7 scripts and docs are intended to remove that dependency.
